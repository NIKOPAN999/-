# 复杂场景下的多模态情感分析

数学建模比赛项目及赛后受控实验归档。项目结合文本、音频与视觉特征进行情感极性分类、强度回归和模态贡献分析。

**状态：比赛已结束，第一阶段探索实验已完成，目前暂停进一步研究。** 仓库保留实际结果，包括未获得稳定性能收益的对照实验。

## 第一阶段结果

实验为比赛原数据与公开 MOSI × `last`、`mean`、`attention`、`text_only` × 随机种子 42、43、44，共 24 组。原提交模型的 32 个验证场景复现通过。

| 数据 | 版本 | 原始三分类准确率（均值） | 原始回归 MAE（均值） |
| --- | --- | ---: | ---: |
| 比赛原数据 | last | 65.11% | 0.5854 |
| 比赛原数据 | mean | 64.24% | 0.5811 |
| 比赛原数据 | attention | 63.83% | 0.5863 |
| 比赛原数据 | text_only | 63.64% | 0.5659 |
| MOSI | last | 80.06% | 0.8471 |
| MOSI | mean | 80.64% | 0.8411 |
| MOSI | attention | 80.64% | 0.8247 |
| MOSI | text_only | 81.22% | 0.8132 |

末状态汇聚对序列后半段缺失更敏感；均值与注意力汇聚减小了前后位置敏感性的差异，但尚未带来跨数据与指标的稳定多模态收益。

这些是**开发集探索结果**，同一验证集参与早停、选模、校准与分析。本阶段没有重新评分测试集；比赛历史已使用过测试数据。MOSI 验证集仅 10 个原视频组。此处采用比赛的负/中/正三分类定义，不能直接与公开论文的 MOSI Acc-2 排名比较。详见[完整结论](docs/phase1-findings.md)。

## 复现入口

在具有相应 CUDA 支持的 PyTorch 环境中安装依赖；本阶段实际运行环境为 Python 3.12、PyTorch 2.8.0+cu128、Transformers 4.44.2，使用 RTX 3080 Ti 12GB。

```bash
python -m pip install -r phase1/requirements.txt
python phase1/phase1.py --help
python phase1/run_stage.py --help
```

具体数据位置、资产下载、验证与训练命令见 [第一阶段运行说明](phase1/README_第一阶段.md)。先准备比赛 `aligned_50.pkl`、MOSI 数据与 BERT 基础参数。`phase1/baseline_manifest.json` 保留原基线哈希；其中 `student_compact.pt` 没有进入 Git，需要从团队原始归档放回 `phase1/baseline/`，才能执行需要原模型的基线校验和复现。不要绕过哈希检查。

原比赛训练入口有测试集评估行为；新研究请使用 `phase1/` 入口并遵守开发集/测试集边界。`phase1/README_第一阶段.md` 中的执行计划保留了实验准备时的流程，最终完成情况以本 README 与结果报告为准。

`analyze_completed.py` 的逐样本独立复算和视频组 bootstrap 需要完整本地结果包中的 `diagnostics/samples.csv`，Git 仓库仅保存其汇总输出。这里没有声称仅下载本仓库就能重建全部实验。
