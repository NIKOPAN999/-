# 支撑材料总说明

本目录是论文《复杂场景下多模态情感预测的数学建模与算法设计》的全部支撑材料，按赛题“四、（二）附件提交要求”组织。论文正文给出全部方法、过程与结论；本目录提供可复现的核心材料与两个专项结果文件。

## 1. 与赛题要求的对应

| 赛题要求 | 位置 | 说明 |
|---|---|---|
| 附件3测试集预测结果CSV | `附件3_预测结果.csv` | 30行。字段：`sample_id`、`polarity_code`（0负向、1中性、2正向）、`polarity`、`intensity`。中性强度恒为0，其余强度符号与极性一致。对应论文6.9节 |
| 附件4测试集预测与解释结果CSV | `附件4_预测与解释结果.csv` | 20行。含极性与强度、三模态Shapley值与份额、主要参考模态、各模态证据片段（原句片段、秒、关键帧号）与证据等级。字段说明见`问题3_可解释预测模型/README_问题3.md`第5节。对应论文7.11节 |
| 问题1：100条样本多模态时序特征文件 | `问题1_词级三模态特征/q1_features_v2.zip` | 每条样本一个目录，含词级特征、词区间、三态标记、各组掩码、原生帧特征与元数据。对应论文5.5、5.7节与附录A、B |

| 问题2：核心代码、说明文档、模型参数、配置、运行环境 | `问题2_鲁棒预测模型/01_代码与参数/` | 代码、INT8/FP16压缩权重、校准文件、训练轨迹、环境与训练条件，运行说明见该目录`README.md`。对应论文第六章 |

## 2. 未放入本目录的内容

- 赛题原始附件1～4：由赛题提供，运行时按各README指定路径读取。
- 公开预训练模型`bert-base-uncased`等：问题二、三只保存训练所得的参数，BERT冻结部分在加载时核对SHA-256指纹；问题一所用wav2vec 2.0、Whisper、OpenFace等工具的版本与来源见论文附录C和问题一复现证据包。
- 按附件2对齐版结构导出的问题一特征`q1_aligned50.pkl`（约16.6 MB）：受总体积限制未放入，可用特征包内`code/export_att2_format.py`重新生成。
- 基线对比所用的MulT、MISA、ALMT、Self-MM等基线权重（单个数百MB）：只提供导出脚本与逐场景结果。

## 3. 运行环境概要

- 问题一：Linux GPU服务器，Python 3.12.3、PyTorch 2.8.0+cu128、transformers 4.57.6、WhisperX 3.8.6、openSMILE 2.6.0、OpenFace（源码编译）、FFmpeg 7.1.1；MFA 3.4.2在独立的Python 3.11环境中运行。
- 问题二：原训练环境为PyTorch 2.3.0+cu121、Transformers 4.44.2；见`01_代码与参数/environment.json`与`requirements.txt`。
- 问题三：Python 3.12、PyTorch 2.8.0+cu128、Transformers 4.57.6；见`README_问题3.md`。
