# 问题一：当前实现与结果使用说明

## 特征和共同时间轴

使用赛题提供的转写。BERT输入保留标点上下文，依据字符偏移将WordPiece映射回原词，同一词的最后一层隐状态取均值，得到768维文本向量。特殊词元不进入问题一的词时间轴。

音轨转换为16kHz单声道PCM。openSMILE提取eGeMAPSv02的25维低层描述符，使用其输出的实际起止时间。OpenFace对按PTS顺序解码的视频帧进行单人跟踪，保留17个AU强度、3个头部姿态角和2个视线角，共22维；只有success=1、confidence≥0.8且数值有限的帧才参与聚合。

共同原点取首个视频帧PTS与首个音频帧PTS的最小值。对齐器的WAV时间加上音轨起始偏移；视频帧覆盖区间由当前PTS与下一帧PTS确定，末帧使用实际帧时长或中位帧间隔。不能只按标称FPS将词位置映射成帧号。若音轨存在明显时间不连续，程序拒绝使用简单偏移映射。

设词区间为I_i=[s_i,e_i)，模态m的有效帧区间为J_j=[u_j,v_j)，掩码为q_j。权重

\[
w_{ij}=q_j\max\{0,\min(e_i,v_j)-\max(s_i,u_j)\},\qquad
x_i^{(m)}=\frac{\sum_j w_{ij} f_j^{(m)}}{\sum_j w_{ij}}.
\]

只有分母大于0时，该词该模态的掩码才为True。否则存零向量、掩码False。原生声学帧和视觉帧同时保存，因此可重新聚合，不必将零向量误读为真实观测。

## 输出结构

每条样本位于run/samples/<key>，key与样本ID的映射在原manifest及metadata.json中。

| 文件/字段 | 内容 |
|---|---|
| aligned.npz / text | L×768，逐词文本特征 |
| aligned.npz / audio | L×25，逐词声学特征 |
| aligned.npz / vision | L×22，逐词视觉特征 |
| word_intervals | L×2，视频共同时间轴；不可对齐的词为[-1,-1] |
| alignment_mask、text_mask、audio_mask、vision_mask | True表示有效，不是“缺失” |
| padding_mask | 变长输出全部为True；True表示真实词位 |
| native.npz | 原生帧特征、帧时间、视觉置信度及有效掩码 |
| metadata.json | 原始文本、词表、WordPiece映射、维度名称、视频时间信息及告警 |
| complete.json | 核验用SHA256、质量统计和状态 |

通过np.load(path, allow_pickle=False)读取数组。不要仅凭complete.json存在判断成功，应验证其中的文件哈希。features生成完成和人工质量验收是两个状态。

这些特征维度为768/25/22，附件2及baselines用的是另一套768/74/35维特征。当前结果用于问题一，不能不改输入层就代入问题二已训练的模型，也不能将两套特征混为同一实验协议。

## 对齐对照的证据边界

试验样本为-3g5yACwYnA$_$13，两种工具均输出15/15个词时间，但平均边界差异258.77ms，P95为1197ms。该统计衡量工具间差异，不能称作对齐误差或准确率。保留了带音频的alignment_review.html及空白人工参考模板；未填写虚构的人工真值。

分歧主要集中在句首前5个词：它们的起止边界绝对差平均709.9ms；后10个词的同一指标仅33.2ms。视频音轨在原稿句子之前已有语音，MFA把句首词提前对齐到这段语音。这是本例的可观测差异，不能直接推断两工具在其他视频上的平均表现。

同一Wav2Vec2模型的非约束解码提示原稿前还有额外语音，并把They've识别在1.44秒附近，与WhisperX一致。因而暂选WhisperX处理100条视频；这一依据是同模型辅助诊断，不能代替人工边界验证。

置信度低于0.3仅用于发现需要复核的词，不是经过真值标定的概率阈值。视觉低覆盖也可能由无人物画面、字幕、遮挡或侧脸导致。只要掩码与原始输出被正确保留，这些样本仍是提取完成的结果，不能编造人脸特征填补。

## 附件4交付给问题三的接口

att4_word_times.csv保留每条text_bert的全部50个位置，包括CLS、SEP和PAD。sample_id为两位字符串，读取时应保留前导零；token_pos为从0开始的位置。

start_sec、end_sec为-1的特殊词元、填充位或纯标点没有可用证据时间。一个原词拆分为多个子词时，这些位置共享词区间，合并证据时应按word_idx去重。align_conf是WhisperX分数，不是边界正确概率；低分位置参见att4_low_confidence_tokens.csv。时间戳只提供定位候选，不自动证明该词是情感预测的因果依据。
