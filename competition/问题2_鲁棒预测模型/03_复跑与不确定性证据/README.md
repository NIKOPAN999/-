# 定型模型复跑与区间证据

这些文件由`01_问题二模型代码与参数/`中提交的定型权重、匹配校准文件，以及赛题原始附件2、附件3生成。独立复跑在2026年9月26日完成，使用另一套兼容环境（PyTorch 2.8.0、Transformers 4.57.6）。复跑不是重新训练，亦未用附件3调整模型。

| 文件 | 用途 |
|---|---|
| `valid_reproduced.csv`、`test_reproduced.csv` | 附件2各32场景复跑四指标；与原提交表在四位小数一致 |
| `attachment3_reproduced.csv` | 附件3共30行；与正式提交CSV逐字节一致 |
| `valid_sample_evidence.csv`、`test_sample_evidence.csv` | 固定模型和固定校准下的逐样本真实标签及原始、文本末段50%遮挡预测 |
| `bootstrap_check.py`、`valid_video_bootstrap.csv` | 从valid逐样本预测重算论文6.8节的配对区间，按239个video_id分组有放回抽样2000次，种子20260925 |

表13的指标差定义为“文本末段50%遮挡减原始输入”。重新计算得到Accuracy −0.0934、macro F1 −0.0924、MAE +0.0806、Pearson −0.1206；95%区间四位小数分别为[−0.1281,−0.0578]、[−0.1314,−0.0538]、[+0.0476,+0.1153]、[−0.1841,−0.0581]。这是固定模型在valid样本条件下的不确定性估计，不能解释为跨训练随机种子的稳定性。

`valid_sample_evidence.csv`和`test_sample_evidence.csv`由核心代码目录的`export_sample_evidence.py`导出；它们含数据集原始ID、真实标签与预测，**仅作为评审核验材料，不得用于重新选模或调校准**。复算方法见核心代码目录README。赛题原始数据及公开BERT基础权重因体积不在本提交目录中。

## 一般性缺失形态压力测试（valid，定型模型不变）

`stress_generalization.py`在官方附件2 valid上以预先固定的规则比较：(1)文本中段50%单块与以1个保留位置隔开的双块，总标称遮挡位置数相同；(2)三模态各中段30%同步遮挡与文本前段、语音中段、视觉末段各30%的错位遮挡。双块构造对723/728条样本可形成两个非空块，其余退化为相同名义遮挡量的单块。结果由脚本直接写入`valid_generalization_metrics.csv`和逐样本CSV：

| 场景 | Accuracy | macro F1 | MAE | Pearson |
|---|---:|---:|---:|---:|
| 文本中段50%单块 | 0.5783 | 0.5462 | 0.6495 | 0.5184 |
| 文本中段50%双块 | 0.5701 | 0.5349 | 0.6529 | 0.5211 |
| 三模态中段30%同步 | 0.6181 | 0.5867 | 0.6066 | 0.5799 |
| 三模态各30%错位 | 0.6181 | 0.5695 | 0.6131 | 0.5828 |

这些是**固定模型的四种受控场景**：双块分类指标略低，同步/错位的Accuracy相同而macro F1不同。双块和单块的具体位置并非完全一致，视觉原始零向量使“30%标称遮挡”不等于新删去30%的可观测信息，因此不能把差值归因于缺失块数量或时间错位的纯粹因果效应，也不能据此宣称覆盖所有真实缺失形态。未使用附件3生成遮挡规则、选模型或调参。
