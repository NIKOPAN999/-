# 关键消融：三版本×三种子同环境复跑

2026年9月26日，使用官方附件2 `aligned_50.pkl`、同一公开 BERT 基础权重、同一实验副本和环境（PyTorch 2.8.0、Transformers 4.57.6），将 `full`、`no_mask`、`no_aux` 分别以训练种子 42、43、44 重新训练。九次训练只改变两处预设因素：`full` 的连续遮挡概率为 0.55、辅助损失权重为 0.4；`no_mask` 仅将遮挡概率设为 0；`no_aux` 仅将辅助权重设为 0。每个子目录的 `settings.py`、`training_conditions.json`、`training.jsonl`、`epoch_metrics.csv` 和 `compact_valid_calibrated.csv` 对应一次训练及其 32 场景验证结果。验证集同时用于选轮次和校准，结果有同集乐观偏差；测试集、附件3无标签数据不用于选模或调参。

六个预定场景为原始输入、文本中段30%、文本末段50%、语音中段30%、视觉中段30%和三模态同步中段30%。先在每个场景算指标，再取六场景算术平均。`summary_by_seed.py`从九份原始 CSV 生成 `comparison_by_seed.csv`；`plot_ablation.py`从同一批 CSV 绘制消融对比图（论文6.7节图表另行重绘），图中“完整模型减消融模型”为配对差，MAE 已反向，使正值统一表示完整模型占优。

**主要结论。** 关闭训练期连续遮挡，文本末段50%场景的 Accuracy 在三个种子分别降低 7.83、15.80、10.99 个百分点，均与“训练时模拟缺失”的建模动机一致。六场景平均 Accuracy 的完整模型优势分别为 0.0410、0.0472、0.0449。不过原始输入场景并非三个种子均占优，须承认正常输入与缺失输入的取舍。关闭辅助损失的六场景平均 Accuracy 配对差为 +0.0066、+0.0016、−0.0064；辅助分支的净收益不稳定。早期单次汇总给出的相反排序缺少完整训练档案，不能将其作为确定的结构结论。

`no_aux_s42` 已导出验证最优权重、校准和完整 32 场景验证结果，后续额外 ZIP 打包因实验副本缺少说明文件而中断；缺失文件已补齐。其验证结果可用，但不声称那次自动打包或测试流程完成。其余新增种子训练流程正常退出。附件仅保留配置、日志、验证结果和绘图程序，按总附件限额不附九组新权重；所需赛题数据和公开 BERT 基础权重亦不重复提交。

此次消融是**新训练权重**的对照；正式附件3仍由 `01_问题二模型代码与参数/student_compact.pt` 定型权重生成，不根据补实验更换。定型权重的推理复现、逐样本预测及压力测试见附件03。原训练与本次兼容环境不同，CUDA运算亦未保证逐位确定，不能声称与早期训练逐位一致。运行核心 `run.py train` 时，应分别读取各子目录的 `settings.py`，并遵循核心附件 README 的数据及基础权重准备步骤。
