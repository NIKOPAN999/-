# 缺失规律与输入变体补充实验

| 文件 | 内容 | 论文位置 |
|---|---|---|
| `scripts/frozen_analysis.py` | 用定型权重与匹配校准在验证集上只做推理：复核32场景指标；剂量—反应网格（文本、语音、视觉、三模态同步 × 比例10%～60% × 前、中、末）；单段与多段缺失形态对照（各5次抽样）；原始输出与符号投影诊断 | 6.4节命题1的核对、6.6.1～6.6.3节 |
| `scripts/variant_runs.py` | 训练三个输入变体：去掉覆盖率输入、去掉逐位观测标记、只用文本；种子42、43、44，其余训练、选轮次与校准流程与定型模型相同 | 6.7节 |
| `frozen/dose_response.csv` | 剂量—反应网格的四项指标 | 6.6.1节 |
| `frozen/pattern_scatter_vs_block.csv` | 相同总比例下单段与多段缺失的对照 | 6.6.3节 |
| `frozen/clean_raw_outputs.csv` | 原始输入下的三类logits、未校准强度与校准后输出 | 6.4节 |
| `frozen/summary.json` | 复核误差与校准参数 | — |
| `variants/<变体>_s<种子>/` | 各变体的配置、训练轨迹与32场景验证集结果 | 6.7节 |
| `att3_missing_stats.json` | 附件3缺失结构统计（段数、段长、每条样本的缺失比例） | 2.2节 |

- 逐样本的中间数组（约0.6 MB）受附件体积限制未放入，可由`frozen_analysis.py`重新生成。
- 脚本按团队服务器的目录布局编写，运行前需修改其中的代码与数据路径；分析只做推理，不改变提交的权重与附件3结果。
